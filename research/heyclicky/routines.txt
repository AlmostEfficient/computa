Source evidence/harness-bundle.js ip/op near 348000–350700 and routinesWrite handler near 429288. No routines read from user state or created.

ip supports create/update/pause/resume; listing is handled separately. Matching is case-insensitive exact title. Title length is capped at 80 characters but the error's 'two to four words' is not enforced. Create requires title, task and cadence, rejects an existing matching title. Cadence must be integer 2–43200 minutes. time_of_day must be HH:MM; it supplies default 1440 minutes and requires cadence divisible by 1440. Thus any whole-day cadence in range is accepted despite error text mentioning only daily/weekly. Explicit timezone is checked through Intl.DateTimeFormat.

Update requires task, interval or new title; a timezone-only update is rejected. A new title is not checked for collision with another routine. Routine payload includes time_of_day/timezone but emitted legacy block omits them. op projects the routine list in memory: updates copy truthy interval/task/title and only change timeOfDay/timezone when time_of_day is truthy. Updating a daily timed routine to hourly can therefore retain its prior timeOfDay in this projection. This does not establish how native persistence handles the event.

routinesWrite emits a routine event with original args, normalized routine and legacy block; it returns 'Created/Updated/Paused/Resumed' text to the model immediately. The inspected handler does not await native scheduler acknowledgment. Main loop stores the normalized routine in its local list and appends the latest legacy block inside <ROUTINE> to final text if not already present. Actual scheduling, deduplication, UI confirmation and native error handling remain untraced; wording is not evidence the schedule has been committed.

Six assertions passed in probes/harness-routines.mjs with synthetic routines: a two-day timed cadence is accepted, legacy block omits time, timezone-only update rejects, hourly update retains prior time in projection, and rename collision is accepted.
