CLAUDE INPUT TRANSLATION
Nf converts the internal Responses-like input to Messages format. The first nonempty system/developer content becomes system text with ephemeral cache control; later system/developer content becomes user text. Adjacent same-role entries merge. Original claude_turn blocks become assistant content, optionally filtering thinking/redacted_thinking. Synthetic normalized outputs marked _claude_skip are omitted to avoid duplicate replay. Function calls map to tool_use and results to user tool_result. Invalid function-call JSON falls back to an empty object. Text input supports text/input_text/output_text; images are accepted only as base64 data URLs by fI, so ordinary HTTP image URLs are dropped at this conversion boundary. Upstream dl may already resolve blobs.

The last block of the final message gets ephemeral cache_control. Function schemas convert to input_schema; non-object schemas become an empty object schema. Hosted web_search becomes web_search_20250305 with max_uses 8. Payload always requests adaptive thinking, stream true, auto tool choice when tools exist, and configured effort/default medium. Output cap is min(requested or 32000, model ceiling); packaged ceiling is 64000 for claude-haiku-5-5, otherwise 32000. Model IDs/capabilities remain packaged configuration, not verified provider support.

STREAMING AND ERROR HANDLING
hI POSTs to configured H1_ANTHROPIC_URL using bearer auth, anthropic-version 2023-06-01, optional body compression and abort signal. Idle timeout defaults 90s and starts before fetch; resets on each read. This differs from Responses adapter's initial 25s deadline. SSE parsing is line-based data: JSON, not multiline SSE reconstruction. It accumulates text, thinking, signatures, citations and partial tool JSON by index; invalid final tool JSON becomes {}. A final stop reason is required, otherwise stream termination is an error. HTTP 408/409/429/5xx is retryable; context-length text and most other statuses become NonRetryableError.

Hf can make up to four streaming requests when stop_reason is pause_turn. It appends the accumulated assistant blocks on continuation. A 'bound to a different conversation' error triggers one retry removing thinking blocks; that choice is remembered by prompt_cache_key in Uf (empty keys share one entry). The continuation payload construction appends all accumulated blocks to an already extended message list, so repeated pause_turn behavior needs further fixture testing. If four attempts all pause, normalization still marks completed unless max_tokens; no explicit pause exhaustion error is present.

NORMALIZED OUTPUT AND USAGE
gI preserves original content as claude_turn, then creates additional assistant messages, function_call, reasoning summaries and web_search_call entries tagged _claude_skip. Consecutive text blocks merge. Reasoning text is exposed to internal reasoning event handling; tool calls are emitted after the adapter finishes collecting, unlike the Responses onItem stream path. Web search start can emit earlier. Tool result sources retain URLs but converted text annotations are empty; original citations remain in the preserved claude_turn.

Usage sums input_tokens, cache_read_input_tokens and cache_creation_input_tokens into normalized input, exposes cached tokens separately, and reports output tokens with reasoning_tokens 0. Generic To then reports cache_write 0, so the event schema loses the distinct cache-creation amount. max_tokens maps incomplete/max_output_tokens; model_context_window_exceeded throws. A refusal without nonblank text gets a fallback response. Other stop reasons map completed, including tool_use and residual pause_turn.
