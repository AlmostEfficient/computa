RUNNER HOST IPC (source character offsets ~310900–315300)
The outer runner binds an ephemeral port on 127.0.0.1 and prints a single JSON ready/port line on stdout. Every HTTP request requires exact Authorization Bearer matching nonempty CLICKY_HARNESS_TOKEN. State root is CLICKY_HARNESS_STATE or cwd/.state. Stdin end or SIGTERM/SIGINT/SIGHUP exits the process. Routes: POST /turn, /prewarm, /steer, /cancel and GET /events. Only h1-mac is registered in the extracted bundle's final call; no prewarm hook is passed, so the default returns false.

Per-conversation in-memory state has events, sequence, waiters, running flag, cancellation count and turn count. /turn selects driver by harness-place, waits at most 25s for an existing run (100ms polling), then rejects if still running. A cancellation during that wait emits interrupted without starting the new run. Each launched run gets turnRef t<N>; errors become a failed turn_end event. State directory sanitizes job IDs to ASCII alphanumeric, underscore or hyphen and truncates to 100 characters; collisions are possible by construction, but none were observed in user data (no user state inspected).

Event retention is 2000 per conversation. /events filters seq>after, returns only the first 400, but latest is the overall current sequence. Consumers must advance from returned events rather than blindly skipping to latest when >400 are pending; native consumer behavior remains untraced. Long polling caps wait at 25000ms. Timed-out waiters remain registered until a later event drains them. Request bodies are accumulated before JSON parsing with no explicit size cap in this route. These are source observations, not runtime/load tests.

LOCAL MCP TRANSPORT (class $_, functions Z2, n5, y_; source ~477000–487600)
Protocol version 2025-06-18. Initialize deadline 120s; normal RPC/forward deadline 1200s. Stdout accumulates newline-delimited JSON with a 67108864-character buffer ceiling; the ceiling check occurs before splitting lines. Blank/malformed lines are ignored, arrays dispatched itemwise. Server requests support ping only, otherwise -32601; notifications are ignored by response handling. Caller requests get private incrementing IDs, then original IDs restored in replies. HTTP disconnect cancels pending forwarding and sends notifications/cancelled. Ordinary timeout deletes pending state but does not itself send that notification.

Connector subprocess env inherits process.env except keys starting CLICKY_, OPENAI_ or ANTHROPIC_ (case insensitive); explicitly configured string env values are applied afterward and can reintroduce such names. This is not blanket credential filtering. Working directory is home; stdio piped; macOS child detached into a process group. Error tail retains 4000 characters, redacts configured env values of length >=4 except PATH, then includes last three lines clipped to 300 chars. Shutdown sends process-group SIGTERM with child fallback; no forced-kill escalation visible in this method.

Local HTTP proxy uses random 24-byte token, timing-safe equal-length bearer comparison, ephemeral loopback port and /mcp/<24-hex-id>. POST only, one non-array JSON RPC object per request; notifications return 202. Request and headers timeouts explicitly zero; body accumulation has no explicit cap here. Connector cache is keyed by name, fingerprinted by command, args and sorted env. Changed definition stops/replaces the prior child. Idle children stop after 10min with 60s sweep; in-flight/startup state prevents idle termination. Proxy/server stay cached and children can restart. Startup errors are logged while conversion still returns an optional connector descriptor.

LOCAL ENGINE AND PERSISTENCE (source ~443500–465300)
The local endpoint p_ calls f_, which configures global model URLs under worker.base: /agent/openai/v1/responses, /agent/anthropic/v1/messages and /agent/web-search. Session token is stored in the module's pf object and used by the local workflow. Therefore local execution does not mean offline inference. f_ updates these globals before returning its cached server, so later initialization can replace the endpoint/token for that process. No actual endpoint was called during this analysis.

The inner job server has a separate random 24-byte bearer token, binds ephemeral loopback, and disables request/header timeouts. Its /jobs subroutes implement blob, start, turn, answer, steer, interrupt, cancel, events. Only top-level job creation explicitly checks POST; subroute switch itself does not check method. Auth remains required. Local /files consumes and discards the payload, and workspace.tgz returns 409 because the engine works directly in the original folder.

Job IDs must match 1–100 ASCII letters/digits/underscore/hyphen. Disk root defaults to ~/Library/Application Support/Clicky/AgentHarness/h1-local, overridable by CLICKY_H1_STATE_DIR. These paths were inferred from code, not read from the user's state. JSON files use write-to-PID-suffixed-temp then rename; JSONL records append synchronously. Blob names use encodeURIComponent. Read errors use defaults; malformed JSONL lines are skipped. Startup cleanup removes entries whose directory mtime is more than 30 days old; no recursive activity-age inspection is visible in w2.

Inner job events deduplicate on supplied key or generated kind/UUID, increment sequence and append events.jsonl, except note preview events. Memory retains the most recent 3000 events; each poll returns at most 400 and a done flag, with up to 25s wait. The inner wait implementation unregisters timed-out waiters (unlike the outer runner implementation). job_end sets done and saves metadata. Detailed restore contents and full workflow state are still pending tracing.

The Io workflow adapter persists step outcomes in steps.jsonl. Repeated step names get occurrence suffixes; replay returns recorded values or throws recorded errors. It implements configured retry count/delay and optional doubling backoff, with NonRetryableError short circuit. Waits for turn-N have no timeout; other waits default to six hours. Local jobs can be restored on lookup, unless marked done, then restart the workflow using its persisted steps. This explains recovery machinery, not a guarantee of exactly-once external effects.

Local boxTool deduplicates completed calls by ID in memory, attaches an AbortController while running, dispatches n_ with workspace/env and a default 300s shell timeout, and stores returned image data as blobs. Interrupt aborts the current model signal plus running tools; cancel aborts tools and marks the job done, and the route also terminates workflow waits. n_ invokes locally constructed tool implementations; errors become isError text results. execEnv filters inherited CLICKY_/OPENAI_/ANTHROPIC_ prefixes case-sensitively, sets HOME and GIT_CEILING_DIRECTORIES, optionally TZ, then overlays cfg.env. Connector filtering elsewhere is case-insensitive; these are distinct implementations.

RESTORE AND STEERING FOLLOW-UP
Ef.restore reads cfg/done/started from job.json, turns from turns.json, flags from flags.json and events.jsonl. It retains last 3000 events in memory but builds deduplication keys from the entire log. Restored seq is last recorded seq +1000, deliberately leaving a gap. A started latest turn without a turn_end key is marked cutOffTurn; O2 interrupts it before replaying the workflow. The completed box-call cache, pending steering notes, per-model notes and script store are not directly restored by this method; workflow step replay can reconstruct some state. This is not proof of lossless restart across every crash point.

beginSteering refuses an already-ended turn; otherwise it resets per-model note cache and sequence and enables steering unless interrupted/cut off. takeNotes drains queued notes once per model-step name and caches them so a retry receives the same notes/metadata; new messages remain queued for a subsequent model step. finishOrTakeNotes allows late notes to continue a completed turn, but disables acceptance if unsuccessful, interrupted, done or cut off.

addNote has a special future-turn branch: a numeric turn greater than current can be accepted when not done and not already ended, even if the current turn is interrupted or ordinary acceptance is false. Otherwise it rejects mismatched/not-running messages. Nonblank text is required; image-only steering is rejected. At most eight existing blobs are attached and MIME is normalized to PNG or JPEG. Notes are queued in memory with a sequence receipt; this method does not persist them immediately.

Eight isolated assertions in probes/harness-steering.mjs verified model-retry note reuse, newly queued notes waiting for the next model step, rejection for an interrupted current turn and acceptance for a future turn. Evidence: evidence/harness-steering-probe.json. No real job state or blobs read. Native request sequencing and crash behavior still need correlation.
